# CPGSR Reader Reorganization Changelog

## 2026-08-22

### Navigation and Learning Index

- Added a stable content registry and compatibility mapping for legacy page hashes and numeric page calls.
- Added a learning index with 12 reading-workflow stages, 17 topic groups, synonym search, filters, URL query state, and keyboard-accessible views.
- Added direct routes between the chapter reader, statistics, non-RCT, oncology, meta-analysis, and Guyatt methodology materials.

### Methodology Pages

- Added Guyatt's methodology atlas, structured by the reader's question rather than a biographical list.
- Added the 19-module meta-analysis methods page, covering estimand, heterogeneity, rare events, time-to-event data, IPD, NMA, component NMA, RCT plus NRSI synthesis, living evidence, and GRADE.
- Marked each source strip with its material status and a verification date.

### Reader-Facing Corrections

- Removed universal or fixed interpretations of absolute effects, I2, OIS, MID crossing, and conditional recommendation.
- Clarified the different roles of PRISMA 2020, AMSTAR 2, ROBIS, Risk of Bias tools, certainty, recommendation, and EtD.
- Reorganized formal citations so incomplete placeholders remain visibly separate from verified references.

### QA and Preservation

- Added repeatable static checks for baseline preservation, routing, links, IDs, source metadata, citations, and the learning index.
- Added a content preservation report and a QA matrix for responsive and keyboard testing.
