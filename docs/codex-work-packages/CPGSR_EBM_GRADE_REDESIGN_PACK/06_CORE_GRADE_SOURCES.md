# 「Core GRADEとは」章の一次資料

新しいトピックでは、人物関係を推測で書かず、以下を基礎資料にしてください。

## 1. GRADE Working Group

- [GRADE Working Group official website](https://www.gradeworkinggroup.org/)

確認事項：

- Working Groupは2000年に始まった国際的協働
- certainty of evidenceとstrength of recommendationsを透明に評価する方法を共同開発
- G3の役割
- 公式guidanceと個人資料の区別

## 2. GRADE Book

- [GRADE Book — How to Use / About](https://book.gradepro.org/about)
- [GRADE Book — Overview of the GRADE approach](https://book.gradepro.org/guideline/overview-of-the-grade-approach)
- [GRADE Book — The development methods of GRADE](https://book.gradepro.org/guideline/the-development-methods-of-grade)
- [GRADE Book — The history and evolution of GRADE](https://book.gradepro.org/guideline/the-history-and-evolution-of-grade)
- [GRADE Living Map](https://book.gradepro.org/map)

確認事項：

- GRADE BookはGRADE Working Groupの公式publication
- living形式
- Ignacio NeumannとHolger Schünemannがeditorsとして示されている
- 章はeditorial reviewとG3 review/approvalを受ける
- 既存guidanceの変更はWorking Group全体の承認が必要
- current / partially up-to-date / outdatedを区別

## 3. Core GRADE 2025

- [Core GRADE 1: overview of the Core GRADE approach](https://www.bmj.com/content/389/bmj-2024-081903)
- [Core GRADE 7: principles for moving from evidence to recommendations and decisions](https://www.bmj.com/content/389/bmj-2024-083867)

確認事項：

- 7論文シリーズ
- GRADE essentials / core judgmentsに焦点
- PICO、certainty、SoF、EtD、recommendationを一続きに扱う
- Gordon Guyattが中心著者
- Core GRADEシリーズとGRADE Bookは同じものではない

## 4. 旧Handbookの位置づけ

- [GRADEpro — How to cite](https://www.gradepro.org/cite)

旧HandbookのeditorsとしてSchünemann、Brożek、Guyatt、Oxmanが示されています。

古いHandbook、JCE GRADE series、BMJ Core GRADE、GRADE Bookは、発行時点と役割を分けて表示してください。

## 5. ページ内で避ける表現

- 「GuyattがGRADEを単独で作った」
- 「Schünemann版GRADEとGuyatt版GRADEがある」
- 「Core GRADEがGRADE Bookを置き換えた」
- 「GRADE Bookの全記述がGuyatt個人の考え」
- 「講演内容はすべて公式GRADE guidance」
- 「古典的論文は現在も無条件に最新」

## 6. 推奨する関係図

```text
EBM / Users' Guidesの発展
        │
        ├─ Guyattを含む多数の方法論家
        │
        ▼
GRADE Working Group
        ├─ GRADE Guidance Group（G3）
        ├─ GRADE Guidelines / official guidance papers
        ├─ GRADE Book（公式living resource）
        └─ Core GRADE 2025（中核判断を簡潔に示す査読済みシリーズ）

Guyatt：
EBM・GRADE・Core GRADEの主要な方法論的貢献者

Schünemann：
GRADE方法論・運営・教育、GRADE Book編集・現行体系化の主要な貢献者
```

人物を権威ランキングとして並べるのではなく、**資料の種類と公式性の経路**を理解させる章にしてください。
