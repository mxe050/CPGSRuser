EBM BASIC / E1

EBM BASIC：GRADEへ進む前の土台

GRADEはEBMと別の流れではありません。最良の研究エビデンス、臨床専門性、患者の価値観・選好、臨床状況を統合して判断するEBMの延長上で、確実性評価と推奨作成を透明にします。

この段階で答える問い

いま読んでいるものは原著、SR、CPGのどれか。誰が、どの判断のために、どの種類のエビデンスを必要としているか。

60秒要約

EBMは論文の結果だけを機械的に適用する方法ではありません。Ask、Acquire、Appraise、Apply、Assessを通じて、研究の妥当性と結果を読み、目の前の患者の状況・価値観と統合します。SRは複数研究を体系的にまとめ、CPGはそのエビデンスを推奨へつなぎます。

詳しく学ぶ

EBMとCPG・SRの読み方原著、SR、CPGの役割と、読み手が最初に確認する問い。 初学者向け徹底解説EBM、SR、CPG、GRADEを順番に学び直す。 批判的吟味妥当性、結果、適用可能性を分けて読む。 EBM 5A × Core GRADEEBMの作業とGRADE工程の対応を確認する。

EBM BASIC / E2

批判的吟味：妥当性・結果・適用可能性

研究方法が妥当か、結果はどの程度か、その結果を自分の患者へ適用できるかを、順番を崩さずに確認します。

この段階で答える問い

結果を歪めるバイアスは何か。効果の大きさと不確かさは何か。対象患者・介入・比較・アウトカムは臨床疑問と合うか。

60秒要約

統計学的有意差から読み始めると、設計上の問題を見落とします。まずMethodsとプロトコルで妥当性を確認し、次に効果量と95%信頼区間を読み、最後にベースラインリスク、負担、価値観を含めて適用可能性を考えます。

詳しく学ぶ

JAMA Users' Guides：SR／MAを監査する検索、選択、Risk of Bias、統合の妥当性を確認する。 Risk of Bias結果が歪む経路を、研究とアウトカムごとに読む。 統計学・因果推論効果指標、CI、設計、モデルの仮定を深掘りする。 患者への適用外的妥当性と個別判断を区別する。

MAIN MAP / MAP 1

Clinical Question（PICO）

よい答えを探す前に、誰に、何を、何と比べ、何が起きるかを、時間軸と設定まで含めて定めます。

この段階で答える問い

Population、Intervention、Comparator、Outcomeは何か。追跡期間、診療設定、効果修飾、推定したい治療効果は明示されているか。

60秒要約

PICOは検索語を作るだけの枠ではありません。研究の選択、重要アウトカム、estimand、非直接性、推奨の対象範囲を決める出発点です。観察研究では、比較開始時点と治療方針をそろえるtarget trialの発想にもつながります。

詳しく学ぶ

臨床疑問と文書種別原著・SR・CPGのどれが問いに答えるか。 GRADEの全体像PICOから確実性・推奨までを一続きに見る。 estimand何の効果を推定するのかを明示する。 target trialとtime zero非RCTで比較の出発点をそろえる。

MAIN MAP / MAP 2

重要アウトカムを決める

患者にとっての生存、症状、機能、生活の質、重大な害を先に置き、測りやすい代替指標と区別します。

この段階で答える問い

このアウトカムは患者に重要か。意思決定を変えるcritical outcomeか。利益と害の双方、時間軸、測定方法、欠測は扱われているか。

60秒要約

重要アウトカムは、結果を見た後で都合よく選びません。患者の価値観・選好を踏まえて事前に定め、surrogateしかない場合は患者重要アウトカムへのつながりと非直接性を明示します。

詳しく学ぶ

SoF表アウトカムごとの効果と確実性を読む。 がんアウトカムOS、PFS、PRO、害、surrogateを患者重要性から読む。 定性研究・CERQual患者・医療者の経験や受容性を扱う。 価値観・選好アウトカムの重みづけを個別判断へつなぐ。

MAIN MAP / BRIDGE

批判的吟味からSR・メタ分析へ

個別研究の結果を並べるだけではSRになりません。事前の問い、検索、選択、Risk of Bias、統合可能性を一つの方法として確認します。

この段階で答える問い

研究を再現可能に探し、選び、批判的に吟味したか。同じestimandを統合しているか。異質性と欠測エビデンスを説明できるか。

60秒要約

メタ分析はSRの一部であり、計算を行っただけではSRの信頼性は保証されません。統合しない判断も含め、プロトコル、適格基準、各研究の効果推定値、Risk of Bias、モデルと仮定を追います。

詳しく学ぶ

SR／MAの方法を監査するJAMA Users' Guidesの問いで読む。 PRISMA・AMSTAR 2・ROBIS報告、批判的吟味、Risk of Biasを区別する。 メタ分析の数理と現代的方法重み、異質性、稀なイベント、NMAを深掘りする。 ネットワークメタアナリシス直接・間接比較とtransitivityを読む。

MAIN MAP / MAP 3

エビデンスの確実性評価

確実性は研究1本の格付けではなく、重要アウトカムごとの効果推定値について、真の効果が判断閾値のどちら側または範囲内にある確信です。

この段階で答える問い

どのアウトカム、どの効果指標、どの閾値を対象に確実性を評価したか。評価を下げた、または上げた理由は効果推定値と結びついているか。

60秒要約

RCTか非RCTかで開始点を確認し、Risk of Bias、不一致性、非直接性、不精確さ、publication/dissemination biasを明示的に判断します。非RCTで上げる場合はlarge effectとdose-responseを検討し、アウトカムごとに結論を残します。

6つの入口

開始点と4段階High、Moderate、Low、Very lowの意味。 Risk of Bias結果が歪む経路。 不一致性研究間の効果の違い。 非直接性PICO・estimand・surrogateのずれ。 不精確さCIと意思決定閾値。 Dissemination bias欠けた研究・結果・解析。

MAIN MAP / SoF

SoF：効果の大きさと確実性をまとめる

SoFは単なる結論表ではありません。重要アウトカムごとに、相対効果、絶対効果、95%信頼区間、確実性、脚注を結びます。

この段階で答える問い

効果量は患者に意味のある絶対差で示されているか。ベースラインリスク、時間軸、MID・閾値、確実性の理由を同じ行で追えるか。

60秒要約

相対効果だけでは患者への影響を読めません。適切なベースラインリスクから絶対効果へ変換し、CIが判断閾値をまたぐかを確認し、アウトカムごとのcertaintyと脚注を添えてEtDへ渡します。

詳しく学ぶ

相対効果と絶対効果RR、OR、HR、RD、NNTを区別する。 MID・意思決定閾値・CI判断が変わる線を事前に置く。 SoF表・Evidence Profile効果と確実性をアウトカムごとに読む。 不精確さCIが残す臨床判断の不確実性。

MAIN MAP / MAP 4

Evidence to Decision（EtD）

SRとSoFだけで推奨は決まりません。エビデンスを、患者と社会の意思決定に必要な判断基準へ接続します。

この段階で答える問い

利益と害、その確実性、患者の価値観・選好、資源利用をどう判断したか。必要に応じて受容性、実行可能性、公平性をどう扱ったか。

60秒要約

Core GRADEでは、利益・害・負担、certainty、価値観・選好、資源を中核として考えます。受容性、実行可能性、公平性などは意思決定の種類と文脈に応じて追加します。基準の名前を並べるだけでなく、各判断の根拠と推奨への影響を残します。

判断をつなぐ

利益・害から推奨へ方向と強さを決める判断を読む。 価値観・選好患者間のばらつきとSDM。 受容性・実行可能性のエビデンス定性的エビデンスを読む。 net benefit・特殊な意思決定単純な単一推定値で表せない場面。

MAIN MAP / MAP 5

推奨の方向と強さ

「推奨する／しない」という方向と、「強い／条件付き」という強さは別の軸です。certaintyだけで強さを決めません。

この段階で答える問い

推奨の対象、介入、比較、方向、強さが明確か。EtDのどの判断が方向と強さを支え、どの患者では条件が変わるか。

60秒要約

方向は望ましい影響と望ましくない影響のバランスに関係し、強さは多くの患者に同じ選択を勧められる確信に関係します。条件付き推奨は「弱い研究」という意味ではなく、価値観や状況で最適選択が変わり得ることを示します。

詳しく学ぶ

強い推奨と条件付き推奨患者・臨床家・政策への含意を読む。 4つの推奨パターン方向2通り × 強さ2通り。 Good Practice StatementエビデンスがないからGPS、ではない。 Guyatt方法論アトラス推奨に関する原著と現行資料をたどる。

MAIN MAP / MAP 5

4つの推奨パターン

推奨の方向と強さを別々に定めることで、4つの基本パターンを読み分けます。

60秒要約

基本は、強く推奨する、条件付きで推奨する、条件付きで推奨しない、強く推奨しない、の4つです。文言だけでなく、対象集団、例外、代替選択肢、EtDの根拠を合わせて読みます。

4つを混同しない

強く推奨するほとんどの患者に望ましい選択となる。 条件付きで推奨する多くでは望ましいが、価値観や状況で選択が変わる。 条件付きで推奨しない多くでは選ばないが、一部では合理的になり得る。 強く推奨しないほとんどの患者で望ましくない選択となる。

MAIN MAP / MAP 6

EBM 5A × Core GRADE

Ask、Acquire、Appraise、Apply、Assessの各作業が、PICO、重要アウトカム、確実性、SoF、EtD、推奨とどう対応するかを確認します。

この段階で答える問い

GRADEの表や推奨を読む作業が、EBMのどの段階を支えているか。推奨を患者へ適用した後、結果と判断をどう振り返るか。

60秒要約

AskはPICO、Acquireは重要アウトカムとSRの探索、Appraiseは批判的吟味とcertainty、ApplyはEtDと共同意思決定、Assessは実装後の評価と更新へ対応します。Core GRADEはEBM全体を置き換えるものではなく、比較エビデンスの要約と推奨判断を明確にする方法です。

対応を詳しく読む

Ask・Acquire臨床疑問と文書種別を定める。 Appraise効果推定値とcertaintyを読む。 Apply患者のリスク・負担・状況へ適用する。 Assess推奨の根拠の鎖と更新可能性を監査する。

MAIN MAP / MAP 6

Apply・Assess：推奨を患者に使い、振り返る

集団への推奨と患者個別の最適選択は同じではありません。適用し、共同で決め、結果を振り返ります。

この段階で答える問い

この患者のベースラインリスク、価値観、負担、併存症、実行可能性は研究集団とどう違うか。適用後に利益・害・負担をどう評価するか。

60秒要約

Applyでは、絶対効果と患者の価値観を使って選択肢を説明します。Assessでは、実装できたか、期待した患者重要アウトカムが得られたか、新しいエビデンスで推奨を見直す必要があるかを確認します。

詳しく学ぶ

患者への適用ベースラインリスクと直接性を確認する。 共同意思決定患者の価値観・選好と選択肢を共有する。 信頼できるCPG判断の鎖を6つの問いで追う。 CPG品質の実例形式と実質を事例で見分ける。

TOPICS / T1

Core GRADEとは：GRADE Working Group、GRADE Book、Schünemann、Guyattの関係

人物を権威ランキングや対立する流派として並べず、どの組織が公式方法を共同開発し、各資料がどの位置づけにあるかを整理します。

最初に押さえること

GRADEは個人が所有する方法ではありません。2000年に始まった国際的なGRADE Working Groupが、certainty of evidenceとstrength of recommendationsを透明に評価する共通方法を共同で開発・更新しています。

60秒要約

GRADE Working Groupが共同開発の母体です。GRADE Guidance Group（G3）は運営・方向・説明責任を支え、GRADE Bookは公式のliving resourceとして現行資料を整理します。Core GRADEは2025年にBMJで公表された7論文シリーズで、比較介入のエビデンス要約と個人患者の推奨に必要な中核判断へ焦点を当てます。GuyattとSchünemannは、役割の異なる主要貢献者であり、対立する二つのGRADE流派ではありません。

Working Groupが公式方法を共同開発します。G3は実行委員会として方針、説明責任、プロジェクト承認を支えます。
